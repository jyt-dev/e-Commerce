## Server (`server/`)

```
server/
├── public/
│   └── temp/                        # Temporary file storage (multer uploads)
├── src/
│   ├── controllers/
│   │   ├── address.controller.js    # Address CRUD operations
│   │   ├── auth.controller.js       # Register, login, logout, refresh, check-auth
│   │   ├── cart.controller.js       # Cart add, get, remove, reduce quantity
│   │   ├── order.controller.js      # Create, list, get, cancel orders
│   │   ├── payment.controller.js    # Razorpay order creation & payment verification
│   │   ├── product.controller.js    # Product listing, detail, add, delete (seller)
│   │   ├── review.controller.js     # Product review operations
│   │   └── user.controller.js       # Profile update, password change, role upgrade
│   ├── db/
│   │   └── db.js                    # MongoDB connection via Mongoose
│   ├── middleware/
│   │   ├── auth.middleware.js       # JWT verification middleware (verifyJWT)
│   │   ├── error.middleware.js      # Global error handler
│   │   └── multer.middleware.js     # File upload middleware (multer)
│   ├── models/
│   │   ├── address.model.js         # Address schema
│   │   ├── cart.model.js            # Cart schema
│   │   ├── category.model.js        # Category schema
│   │   ├── order.model.js           # Order schema
│   │   ├── payment.model.js         # Payment schema
│   │   ├── product.model.js         # Product schema
│   │   ├── productImage.model.js    # Product image schema
│   │   ├── review.model.js          # Review schema
│   │   └── user.model.js            # User schema (bcrypt hashing, JWT generation)
│   ├── routes/
│   │   ├── address.routes.js        # /api/v1/addresses
│   │   ├── auth.routes.js           # /api/v1/auth
│   │   ├── cart.routes.js           # /api/v1/cart
│   │   ├── order.routes.js          # /api/v1/order
│   │   ├── payment.routes.js        # /api/v1/payment
│   │   ├── product.routes.js        # /api/v1/shop
│   │   ├── seller.routes.js         # /api/v1/seller
│   │   └── user.routes.js           # /api/v1/users
│   ├── services/
│   │   └── razorpay.service.js      # Razorpay SDK wrapper (create order, verify, fetch)
│   ├── utils/
│   │   ├── apiError.js              # Custom API error class
│   │   ├── apiResponse.js           # Standardized API response class
│   │   ├── asyncHandler.js          # Async error wrapper for controllers
│   │   ├── cloudinary.js            # Cloudinary upload & delete helpers
│   │   └── escapeRegex.js           # Regex escaping utility (for search)
│   ├── app.js                       # Express app setup (middleware, routes, CORS)
│   ├── constants.js                 # App constants (DB_NAME: "E-COM")
│   └── index.js                     # Entry point (DB connect → server listen)
├── .prettierrc                      # Prettier configuration
├── .prettierignore                  # Prettier ignore rules
└── package.json
```
